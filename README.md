Este repositorio es una bitácora completa de mi aprendizaje y evolución en el desarrollo backend con Python. Contiene ejercicios prácticos, pruebas de concepto (POC) y proyectos integradores organizados cronológicamente.

---

## 📂 Estructura del Repositorio

El aprendizaje está dividido en módulos progresivos, reflejando el avance desde conceptos básicos hasta la integración con bases de datos relacionales:

### 1. Fundamentos y Lógica (`clase_01_py` a `clase_08_py`)
* Variables, tipos de datos y control de flujo.
* Estructuras de datos complejas (Listas, Tuplas, Diccionarios).
* Algoritmia y resolución de problemas con bucles `while` y `for`.

### 2. Modularización (`clase_09_py` y `clase_10_py`)
* Creación de funciones (`def`) y manejo de retornos.
* Principios básicos de código limpio y encapsulamiento.

### 3. Persistencia y Bases de Datos (`clase_12_py` a `clase_14_py`)
* Integración de Python con **SQLite3**.
* Diseño de consultas SQL y ejecución desde scripts.
* Formateo de datos por consola utilizando la librería `tabulate`.

### 4. Proyectos Integradores
* **`clase_pre_entrega_proyecto`**: Primer acercamiento a un sistema estructurado con separación de módulos (lógica, presentación y datos).
* **`clase_PROYECTO_FINAL`**: Implementación de un sistema CRUD completo, aplicando todos los conceptos de la cursada en una arquitectura funcional.

---

## 🛠️ Tecnologías y Librerías Destacadas
* **Lenguaje:** Python puro (Vanilla).
* **Base de Datos:** SQLite.
* **Librerías:** `tabulate` (presentación de datos).
